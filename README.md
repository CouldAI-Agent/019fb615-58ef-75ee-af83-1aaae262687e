# रामायण मूवी टिकट ऐप

यह एक फ्लटर (Flutter) एप्लिकेशन है जो "रामायण" (Ramayan) फिल्म के लिए एक सुंदर और डिजिटल मूवी टिकट जेनरेट करता है। इस ऐप में यूज़र अपनी टिकट देख सकता है और एक सुंदर कार्ड डिज़ाइन में टिकट की पूरी डिटेल्स (जैसे कि तारीख, समय, सीट नंबर, और थियेटर) मौजूद हैं। 

## फीचर्स (Features)
- 🎬 **रामायण का खूबसूरत डिजिटल टिकट**: प्रीमियम कार्ड डिज़ाइन जो देखने में असली टिकट जैसा लगता है।
- 📱 **रिस्पॉन्सिव लेआउट**: मोबाइल, टैबलेट और डेस्कटॉप तीनों पर बेहतरीन लेआउट।
- 🎟️ **टिकट डिटेल्स**: थियेटर, सीट नंबर, और मूवी शो टाइमिंग की जानकारी।
- ⬇️ **डाउनलोड बटन**: टिकट डाउनलोड करने के लिए एक इंटरैक्टिव स्नैकबार नोटिफिकेशन के साथ बटन।

## सेटअप (Setup)
इस ऐप को रन करने के लिए:
1. Flutter SDK इन्स्टॉल करें।
2. रिपॉजिटरी को क्लोन करें।
3. टर्मिनल में `flutter pub get` कमांड रन करें।
4. ऐप स्टार्ट करने के लिए `flutter run` कमांड चलाएं।
