# Spider-Man Movie Ticket App

यह एक खूबसूरत फ्लटर (Flutter) ऐप्लिकेशन है जो **स्पाइडर-मैन (Spider-Man)** फिल्म की एक डिजिटल टिकट प्रदर्शित करता है। इसमें लोकेशन **दिल्ली (Delhi)** के पीवीआर (PVR) सिनेमा की सेट की गई है।

## विशेषताएं (Features)
- **आकर्षक डिज़ाइन:** स्पाइडर-मैन के थीम (लाल और नीले रंग) पर आधारित UI.
- **टिकट की जानकारी:** सिनेमाघर का नाम (दिल्ली), तारीख, समय और सीट नंबर।
- **बारकोड:** टिकट वेरिफिकेशन के लिए एक डमी बारकोड और टिकट आईडी।
- **क्रॉस-प्लेटफ़ॉर्म:** यह ऐप मोबाइल, वेब और डेस्कटॉप पर बिना किसी समस्या के काम करता है।

## तकनीकी जानकारी (Tech Stack)
- **Framework:** Flutter
- **Language:** Dart

## कैसे चलाएं (How to Run)
1. सुनिश्चित करें कि आपके सिस्टम में Flutter इन्स्टॉल है।
2. इस रिपॉजिटरी को क्लोन करें।
3. टर्मिनल में यह कमांड चलाएं:
   ```bash
   flutter pub get
   flutter run
   ```
